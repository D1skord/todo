Подключение к API

Адрес сервера вашего приложения.

Например, http://localhost:5050/api/v1. Настройка сохранится в этом браузере.

При открытии HTML как файла или с другого домена сервер должен разрешать запросы с этого адреса через CORS. Можно разместить страницу на одном домене с API.
